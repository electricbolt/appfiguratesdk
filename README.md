# Appfigurate™ iOS and watchOS integration library

Appfigurate Library for iOS and watchOS apps and app extensions.

Appfigurate Simulator app is installed using the [AppfigurateSE macOS app](https://electricbolt.gitbook.io/getting-started/getting-started#appfiguratese-macos-app).

Documentation for Appfigurate is available at [https://electricbolt.gitbook.io](https://electricbolt.gitbook.io).
